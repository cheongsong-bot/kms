# 제3회 힐링콘서트 30초 홍보 모션그래픽

- `healing-concert-promo-30s.mp4` — 1920x1080, 30fps, H.264/AAC, 30초
- `overlay.py` — 텍스트/모션그래픽 합성 스크립트 (Pillow + ffmpeg)

## 구성 (영상 2배속, 현장음 제거)
| 구간 | 내용 |
|---|---|
| 0–3.7s | 인트로 타이틀 (제3회 안산시민을 위한 / 힐링콘서트) |
| 3.7–8.5s | 청소년 댄스 공연 |
| 8.5–10.8s | 라이브 무대 |
| 10.8–13.6s | 모두가 함께하는 무대 |
| 13.6–16.5s | 4분할 하이라이트 |
| 16.5–19.5s | 시민과 함께하는 힐링 타임 |
| 19.5–22.7s | 후원사 현수막 (자막 없음) |
| 22.7–30s | 엔딩 카드 (일시·장소·주최·후원) |

- `build_base.sh` — 컷 편집·2배속·전환 효과 (ffmpeg)
